# Actividad 1, Levantamientos de requisitos OmniBank

## Instrucciones

A partir del texto anterior, realiza las siguientes tareas en un documento de texto en blanco o en tu cuaderno:

### 1. Identifica las entidades:

- clientes
- cuentas
- transacciones

### 2. Extrae los requerimientos funcionales (RF)

- La base de datos debe registrar el numero de cuentas.
- La base de datos debe registrar el tipo de cuenta.
- La base de datos debe almacenar el nombre completo del cliente.
- La base de datos debe almacenar el numero de identificación fiscal.
